# Docker-движок и colima

Харнесс работает на любом Docker-движке с `docker compose` v2: colima, OrbStack, Docker Desktop. Визард определяет движок сам и запоминает его в `.env` строкой `DOCKER_ENGINE`. Если docker сейчас смотрит в другой движок, чем в прошлый раз, или контекстов несколько, визард спросит, какой взять, и предложит прошлый.

Я рекомендую colima: она бесплатная, без GUI и ведёт себя предсказуемо.

## Установка colima

```sh
brew install colima docker docker-compose
colima start
```

Плагин `docker-compose` brew просит подключить отдельно: следуй его сообщению после установки. Если colima уже стоит и запущена, визард её подхватит. Если стоит, но не запущена, визард даст команду запуска после выбора рабочей папки: ей нужен путь к этой папке.

## Рабочая папка вне домашней папки

colima пробрасывает в свою VM только смонтированные папки, по умолчанию `$HOME` на запись. Если рабочая папка лежит внутри `$HOME`, ничего делать не надо: хватит `colima start`. Если снаружи, контейнер увидит пустую папку, а не твой код. Визард это проверяет на шаге «Рабочая папка внутри движка» и печатает нужную команду:

```sh
colima start --mount /opt/work:w --mount $HOME:w
```

`--mount` заменяет весь список mount, поэтому `$HOME:w` в команде остаётся: там конфиги, которые нужны контейнеру, а запись в домашнюю папку нужна твоим остальным контейнерам в этой VM. Рабочую папку внутри `$HOME` отдельным mount не передавай: colima откажется стартовать с ошибкой `overlapping mounts not supported`. Если у тебя в colima есть свои mount, допиши их сам.

Перезапуск colima останавливает все контейнеры в VM, не только opencode. Визард запускает команду только после твоего подтверждения.

На OrbStack и Docker Desktop этой проблемы нет.
