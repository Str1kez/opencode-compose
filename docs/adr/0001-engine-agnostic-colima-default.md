# Движок Docker: не привязываюсь к OrbStack, визард работает с любым, рекомендую colima

Харнесс поднимает opencode в контейнере, потому что MDM (jamf) убивает нативный бинарь на маке. Первая версия завязана на Docker Desktop или OrbStack. На corporate-маке OrbStack сам нестабилен под jamf — режется сокет, движок приходится рестартить каждые полчаса, — а проект я раздаю коллегам, у которых стек разный. Docker Desktop вдобавок тянет коммерческую лицензию, что на рабочей машине отдельный риск.

Я решил не привязывать харнесс к одному движку. Визард детектит, что доступно (colima, OrbStack, Docker Desktop), и работает поверх любого docker-совместимого сокета. В README и дефолтах рекомендую colima: open-source, без лицензии, ставится через brew.

## Чего я осознанно НЕ делаю

Я не выбираю движок по принципу «что не задетектит MDM-агент». Если jamf рубит сокет движка, смена движка — это гонка вооружений, а не решение: colima это тоже VM, демон и сокет, тот же класс мишени. На jamf-маке colima гарантий не даёт. Правильный путь к стабильности на рабочей машине — allowlist бинаря opencode через IT, а не подбор невидимого движка.

## Consequences

colima монтирует в свою VM только явно указанные пути. WORKSPACE вне `$HOME` не появится в контейнере по тому же абсолютному пути без `colima start --mount $WORKSPACE:w`. Это цена colima против OrbStack, где bind по тому же пути бесплатный. Визард обязан это закрыть: проверить mount и подсказать команду.
