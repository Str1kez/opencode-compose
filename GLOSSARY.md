# opencode-compose

Харнесс, который поднимает сервер opencode в Docker-контейнере и отдаёт ему код с хоста.

## Language

**Рабочая папка**:
Папка хоста, смонтированная в контейнер на запись по тому же абсолютному пути. Это один репозиторий или папка, в которой лежит несколько репозиториев. В конфигурации она задаётся переменной `WORKSPACE`.
_Avoid_: воркспейс, группа репозиториев, маунт

**Репозиторий**:
Git-репозиторий внутри рабочей папки. Если рабочая папка состоит из одного репозитория, они совпадают.
_Avoid_: репа, проект

**Проект**:
Термин opencode: директория, к которой привязаны сессии. Обычно совпадает с репозиторием.
_Avoid_: воркспейс
