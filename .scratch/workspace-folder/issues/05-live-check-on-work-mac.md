# 05: Живая проверка рабочей папки на рабочем маке

**What to build:** Подтверждение вживую того, что я не смог проверить по коду opencode. Визард прогоняется на реальной рабочей папке с несколькими репозиториями (минимум два питон-репозитория и один без питона). Проверяется в браузере, что проект переключается, терминал открывается в папке выбранного проекта, проект, добавленный из браузера, переживает `docker compose restart`, а контейнерный `uv sync` не меняет хостовый `.venv` ни одного репозитория. Результат пишется в комментарий тикета.

**Blocked by:** 01, 02, 03.

**Status:** ready-for-agent

**Исполнение:** человек — нужна рабочая машина с реальными репозиториями и браузер

**Модель реализации:** не применимо, выполняет человек

- [ ] визард проходит с рабочей папкой из нескольких репозиториев; найденные питон-репозитории совпадают с ожидаемыми
- [ ] переключение проекта в браузере открывает сессию в нужном репозитории
- [ ] терминал в браузере стартует в папке выбранного проекта
- [ ] проект, добавленный из браузера, остаётся после `docker compose restart`
- [ ] контейнерный `uv sync` не меняет хостовый `.venv` ни в одном репозитории
- [ ] `git push` из контейнера проходит минимум в двух репозиториях одним ключом
- [ ] результат записан в `## Comments`
