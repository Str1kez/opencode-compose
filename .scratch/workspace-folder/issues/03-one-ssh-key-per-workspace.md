# 03: Один ssh-ключ на рабочую папку

**What to build:** Агент пушит из любого репозитория рабочей папки одним deploy-ключом. Визард выбирает ключ один раз на рабочую папку, правила по ключу (без passphrase, абсолютный путь, запрещённые символы) остаются прежними. Известные хосты он собирает по remote всех репозиториев рабочей папки на любой глубине, дубли хостов не повторяются, fingerprint каждого нового хоста показывается на сверку перед записью в known_hosts. Remote без ssh (https, псевдоним из `~/.ssh/config`) обрабатываются как сейчас: хост пропускается с понятным сообщением. Визард напоминает, что ключ надо подключить в каждый GitLab-проект с правом записи; сам он этого не проверяет.

Обход рабочей папки переиспользует то, что сделано в тикете 02, а не дублирует его.

Решения: [ADR 0005](../../../docs/adr/0005-container-per-workspace-folder.md).

**Blocked by:** 02 (общий обход рабочей папки).

**Status:** ready-for-agent

**Исполнение:** агент

**Модель реализации:** opus, high — ключи, known_hosts и проверка fingerprint, ошибка тихо открывает доступ не к тому хосту

- [x] визард напоминает про подключение ключа в каждый GitLab-проект с правом записи
