# 01: Рабочая папка вместо репозитория в визарде

**What to build:** Визард просит рабочую папку, а не репозиторий. Стадия выбора пути объясняет, что папка должна быть максимально узкой: только репозитории одного уровня доверия, ничего лишнего (личные файлы, dotfiles, чужие проекты). Он прямо говорит, что внутри рабочей папки изоляции между репозиториями нет, а развести разные уровни доверия можно только разными рабочими папками. Если выбранная папка сама git-репозиторий и внутри есть вложенные репозитории, визард предупреждает про opencode #51191 (сессии из подпапки уезжают в корень репозитория). Одиночный репозиторий по-прежнему подходит как рабочая папка. Имя compose-проекта, порт, домашка и проверка colima mount работают как раньше, только привязаны к рабочей папке.

Термины из `GLOSSARY.md`: рабочая папка, репозиторий, проект. Решение: [ADR 0005](../../../docs/adr/0005-container-per-workspace-folder.md).

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

**Исполнение:** агент

**Модель реализации:** sonnet, medium — текст и ветвление в одной стадии визарда, контракты не меняются

- [x] рабочая папка, которая сама git-репозиторий с вложенными репозиториями, даёт предупреждение про #51191; одиночный репозиторий без вложенных предупреждения не даёт
