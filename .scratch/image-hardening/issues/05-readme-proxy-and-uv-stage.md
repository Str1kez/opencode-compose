# 05: README про прокси и стадию uv

**What to build:** Коллега в корпоративной сети по README понимает, как дать контейнеру выход в интернет и почему сборка может упасть на образе uv.

- Без прокси контейнер не скачает opencode с opencode.ai: compose не передаёт `HTTPS_PROXY`. Docker умеет подставлять прокси в контейнеры сам через `proxies` в клиентском конфиге, README показывает этот путь вместо правки compose.
- Стадия uv резолвится даже при `INSTALL_UV=0`: в закрытой сети сборка не-питон проекта падает из-за образа, который в результат не входит. Чинить дорого, документируем ограничение и обход через `UV_REGISTRY`.

**Blocked by:** None (can start immediately).

**Status:** resolved

**Модель реализации:** sonnet, low — документация без ветвлений
